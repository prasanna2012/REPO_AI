# 🚀 RepoAI – AI-Powered Repository Analysis & Debugging

RepoAI is an AI-powered code analysis platform that helps developers understand repositories, identify coding errors, analyze project structures, and receive AI-generated debugging suggestions using Ollama.

## ✨ Features

- **Repository Analysis** – Analyze project files and source code.
- **Code Explanation** – Understand complex code in simple language.
- **Error Detection** – Identify potential bugs and coding issues.
- **AI-Powered Debugging** – Get suggested solutions using Ollama.
- **Code Improvement** – Receive recommendations for better readability and maintainability.
- **Project Analysis** – Review source files and understand project structure.
- **Developer-Friendly UI** – Interact with code analysis through a simple interface.

## 🛠️ Tech Stack

- **Frontend:** React.js, TypeScript, Vite
- **Backend:** Node.js
- **AI Model Integration:** Ollama
- **Package Management:** npm
- **Version Control:** Git and GitHub

## ⚙️ Prerequisites

- Node.js and npm
- Git
- Ollama installed on your system
- A compatible language model downloaded through Ollama

## 📥 Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/RepoAI.git
```

**2. Navigate to the project directory**

```bash
cd RepoAI
```

**3. Install dependencies**

```bash
npm install
```

**4. Download an AI model**

```bash
ollama pull qwen2.5-coder:7b
```

**5. Verify Ollama**

```bash
ollama list
```

**6. Start the application**

```bash
npm run dev
```

Follow the project's configuration for any additional backend startup steps or environment variables.

## 🚀 How It Works

1. Provide project code or supported project files.
2. RepoAI analyzes the available source code and project structure.
3. The AI helps identify potential errors and explain their causes.
4. The application generates debugging suggestions and possible fixes.
5. Review the results and apply appropriate improvements.
